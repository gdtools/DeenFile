# DeenFile
**Language**: [English](README-en.md) | 中文

> 一款快速隐藏(加密)windows文件的工具，只能防止“小孩子乱点”，破解门槛极低。
> 名字由来：Decode Encode Diles

## 特点
- 速度极快
- 支持cli
- 牺牲破解难度提高加密（隐藏）解密（显示）速度
- 功能优先级：无损还原 > 速度 > 可破解
##  工作原理
Windows 目录遮挡工具：把目录藏起来（改名 + CLSID 后缀 + 隐藏属性），文件名乱码化，可选再混淆文件头。**所有变换均可逆**，重装/换机只需同一密码即可完整还原。

## 命令

| 命令 | 需要密码 | 说明 |
|---|---|---|
| `deenfile` | 否 | 交互界面 |
| `deenfile add <dir>` | 是 | 登记目录（首次使用） |
| `deenfile encode` | 否 | 加密全部登记目录 |
| `deenfile decode [force]` | 是 | 解密全部登记目录 |
| `deenfile pwd` | 是 | 修改密码 |
| `deenfile level [1\|2]` | 查询否 / 修改是 | 安全等级 |
| `deenfile list` | 是 | 查看已登记目录 |

交互菜单：`1 encode` / `2 decode` / `3 add` / `4 list` / `5 pwd` / `6 level` / `0 exit`

## 安全等级

| 等级 | 行为 | 速度 |
|---|---|---|
| `1`（缺省） | 目录隐藏 + 文件名偏移，**不碰文件内容** | 快 |
| `2` | 三层全做，额外混淆文件头（前 1024 字节 XOR + 尾 8 字节标记） | 偏慢 |

- 存注册表 `level`，无该键时默认 1
- `pwd` / `level` 修改前都会**先全量解密**，成功才写注册表并按新设置重新保护；任何一步失败即整体放弃，不会留半成品
- **解码与等级无关**：按尾标记决定动不动内容，任何情况下 `decode` 都能完整还原

## 处理的三层

1. **目录隐藏**：根目录改名追加 CLSID 后缀 + 隐藏/系统属性
2. **文件名偏移**：同类字符环内固定偏移（汉字 7919 / 字母 17 / 数字 7），长度严格不变，文件与目录一视同仁
3. **文件头混淆**：仅等级 2 执行；<1024 字节的小文件内容一律不碰

## 使用注意

- 跑 encode/decode 期间**别断电、别杀进程**，看到 `ok` 再动
- **不要用 `decode force`**（会误伤未加密文件）
- `deenfile.exe` 单独存放，**不要放进要保护的目录**（自加密后无法启动）
- 别把受保护目录放进云同步目录
- 密码只存注册表（混淆后），**忘密码且注册表丢失 = 文件头永久损毁**，务必牢记

## 编译

```bash
gcc -O2 -s -municode -o deenfile.exe deenfile.c
```

## 文件

- `deenfile.c` — 全部源码（单文件，无第三方依赖）
- `mkdata.py` / `verify.py` — 测试数据生成与校验脚本
